# 🚀 Data Engineering Projects 

A collection of hands-on Data Engineering pipelines and automation scripts focused on **Extract, Transform, Load (ETL)** workflows, data modeling, and database persistence.

## 🔍 Overview

Each folder in this repository contains a self-contained project solving a specific data ingestion or processing scenario, complete with its own documentation, dependencies, and execution logging.

### 📌 Core Focus Areas
* **Data Extraction:** Automated web scraping, REST API consumption, and flat-file ingestion.
* **Data Transformation:** Schema standardization, data cleaning, unit conversion, and validation using `pandas` and `numpy`.
* **Data Loading & Storage:** Persisting structured and semi-structured datasets into relational databases and portable formats (`JSON`, `CSV`).
* **Observability & Reliability:** Implementing structured audit logs, error handling, and SQL verification queries.

---

## ⚙️ Tech Stack

* **Languages:** Python, SQL
* **Data Manipulation:** Pandas, NumPy
* **Extraction:** Requests, BeautifulSoup4
* **Databases:** SQLite, MySQL
